HƯỚNG DẪN ÁP DỤNG BẢN CẬP NHẬT JANITOR (APPLY)
==============================================

1. Giải nén đè lên thư mục gốc của repo/thư mục tool:
   unzip -o Antertool-janitor.zip -d <repo-root>
   (file này KHÔNG chứa config.json, .env, update.json, revenue.json — dữ liệu của bạn giữ nguyên)

2. Kiểm tra:
   npm run lint
   npm test

3. Dùng thử trong console của tool:
   clean dry      # xem trước sẽ dọn gì, chưa đổi gì
   clean          # dọn ngay
   clean trash    # xem thùng rác (.anter/trash, tự xoá hẳn sau 7 ngày)
   clean copies   # xem trước việc cách ly bản sao mã nguồn cũ cạnh load.js (chỉ khi chạy bằng load.js)

4. Tuỳ chỉnh: thêm khối "cleanup" vào config.json (xem config.example.json). Tắt hẳn: "cleanup": {"enabled": false}.
